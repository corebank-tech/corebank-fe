# 화면 라벨 ↔ 용어 대조 (C-6)

서버 `docs/phase2/tasks.md` FE C-6. 기준일 2026-10-20 `dev`.

## 기준

1. **용어표** — 서버 `docs/phase2/glossary.md`(PH-87). 2차 용어와 §3 화면 라벨의 정본이다.
2. **요구사항정의서** — `corebank-design/docs/CoreBank_요구사항정의서_v1_4.xlsx`(발췌 `requirements.md`). 화면별 표시 항목(컬럼명)을 REQ로 고정한다.

둘이 부딪히면 용어표를 따른다(용어표가 "이 표가 정본이다"로 2차 라벨을 덮는다). 용어표에 없는 라벨은 정의서 문구를 따르고,
**정의서가 화면마다 다른 이름을 지정한 경우는 고치지 않는다** — FE가 정의서를 바꿀 권한이 없다.

대조 범위는 `src/`의 화면 표시 문자열(컬럼 헤더·라벨·버튼·안내문)이다. 생성 코드·목·테스트·스토리는 뺐다.

## 불일치 없음

- 출금가능금액 — 전 화면이 용어표 §3 표기를 쓴다.
- 만기(`MATURED`) — 계좌 상태 배지가 "만기"다(`entities/account/lib/account-status.ts`).
- 전표·분개 — ADM-02 시산표만 쓰며 용어표 정의와 같다.
- 이체주기 · 이체지정일 — 라벨은 전부 정의서 표기다. "지정일"은 안내문에만 쓴다.
